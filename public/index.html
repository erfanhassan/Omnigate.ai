1. Send raw request via CLI (curl)

Test the proxy from any terminal, compiler, or shell environment:

curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-Gateway-Key: stub-agency-key-for-local-testing" \
  -H "X-Gateway-User-ID: developer-erfan" \
  -H "X-Gateway-Project-ID: local-test-v1" \
  -d '{
    "model": "deepseek-v4-pro",
    "messages": [{"role": "user", "content": "Say Hello!"}],
    "stream": true
  }'

2. VS Code (Continue Extension)

Add this model block to your ~/.continue/config.yaml config file:

models:
  - name: DeepSeek (via OmniGate)
    provider: openai
    model: deepseek-v4-pro
    apiBase: http://localhost:8080/v1/
    apiKey: stub-agency-key-for-local-testing
    requestOptions:
      headers:
        X-Gateway-Key: stub-agency-key-for-local-testing
        X-Gateway-User-ID: developer-erfan
        X-Gateway-Project-ID: vscode-project-omega

3. Roo Code or Cline

Choose OpenAI Compatible provider, set Base URL to http://localhost:8080/v1, and add these custom headers in settings:

{
  "X-Gateway-Key": "stub-agency-key-for-local-testing",
  "X-Gateway-User-ID": "developer-erfan",
  "X-Gateway-Project-ID": "roo-code-evaluation"
}

🛠️ Dashboard Features Guide

  • Token Velocity

    Tracks your active token usage (Input vs Output) in real-time. Reflects changes immediately as requests stream through.

  • Estimated Spend

    Calculates cumulative costs based on official provider rates (per 1M tokens) to alert you before any bill shock occurs.

  • Network RPM

    Monitors Requests Per Minute. Crucial for detecting runaway agent loops or automated tool loops.

  • Gateway Config

    Allows saving custom endpoints (DeepSeek, OpenAI, Gemini) and keys. Settings are written directly to your self-hosted instance's disk.

  • Live Interceptions

    Displays an audit trail of incoming requests. Shows timestamp, model, project, user, and precise token costs.

Secure Your Gateway

To use OmniGate AI, you need to configure a Gateway Secret Key. This acts as a password for your local proxy, ensuring only your tools can route traffic through it.

You will use this key in your code editors (VS Code, Roo Code) to authenticate with this dashboard.

Connect Your Tools

Now that your key is set, update your AI coding assistants to route traffic to http://localhost:8080/v1.

Roo Code / Cline

Set Provider to OpenAI Compatible, Base URL to http://localhost:8080/v1, and add Custom Headers:

{
  "X-Gateway-Key": "your-key",
  "X-Gateway-User-ID": "developer",
  "X-Gateway-Project-ID": "my-project"
}
